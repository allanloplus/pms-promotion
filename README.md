# 米數Medsig｜以ISMS為基礎的專案安全管理系統 — 產品宣傳頁

行銷宣傳用的靜態動畫網頁，以 GitHub Pages 發佈。

- `index.html`：單一頁面，樣式與動畫皆內嵌，不載入任何外部資源或追蹤碼
- `img/`：系統畫面截圖（取自示範資料）
- `favicon.svg`：網站圖示
- `course/`：系統線上課程（動畫教學）：線上互動教材版 `course/index.html`、線上課程教學影音版 `course/play.html`、課後測驗與通過證書。說明見 [`course/README.md`](course/README.md)
- `xbom/`：XBOM 對話教學（Allan 顧問與 AI 小助理阿拉蕾）：單一頁面 `xbom/index.html`，角色圖內嵌；`xbom/share.png` 為 Facebook／LINE 分享縮圖（1200×630）
- `security-testing/`：安全檢測對話教學（XBOM 的續篇，去識別化公開版）：單一頁面 `security-testing/index.html`；`security-testing/share.png` 為分享縮圖
- `third-party-report/`：解讀第三方檢測報告（系列第三篇；報告節錄皆為虛構）：`third-party-report/index.html` 與分享縮圖 `share.png`

## 發佈

**Settings › Pages**：Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。

## 修改內容

直接編輯 `index.html` 即可，文案皆為純文字。更換畫面截圖時，以相同檔名覆蓋 `img/` 內的檔案（電腦版 1980×1200、手機版 1170×1992）。
