# 米數資科｜以ISMS為基礎的專案安全管理系統 — 產品宣傳頁

行銷宣傳用的靜態動畫網頁，以 GitHub Pages 發佈。

- `index.html`：單一頁面，樣式與動畫皆內嵌，不載入任何外部資源或追蹤碼
- `img/`：系統畫面截圖（取自示範資料）
- `favicon.svg`：網站圖示

## 發佈

**Settings › Pages**：Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。

## 修改內容

直接編輯 `index.html` 即可，文案皆為純文字。更換畫面截圖時，以相同檔名覆蓋 `img/` 內的檔案（電腦版 1980×1200、手機版 1170×1992）。
